Bronze（Part 1）

音声と PDF は、AI 関数でテキストにしてからテーブルにします。通話の日時・顧客・注文・商品は、音声ではなくメタデータ JSON から取ります（注文番号は音声から正確に聞き取れないため）。

Silver（setup・Part 2）

CSV は最初から整っているので、DIM_・FACT_ は setup で直接ロードし、列に日本語のコメントを付けます。通話と PDF は、Part 2 で AI_COMPLETE の構造化出力（JSON スキーマ）により列を取り出し、注文データと組み合わせて集計できる形にします。

Gold（Part 2）

通話と PDF の本文を、属性（文書の種類・部署・公開範囲・日付・商品カテゴリ・商品ID・感情）付きのチャンクにします。Part 3 の Cortex Search がこれを使います。

件数は 2026-11-25 の検証環境（AWS 東京）での実行結果。AI_COMPLETE のモデルは openai-gpt-5.4-mini。Part 2 の「3. 集計」（ロット別の返品率）は CALL_ANALYSIS と FACT_ORDERS を組み合わせるクエリで、テーブルは作りません。
